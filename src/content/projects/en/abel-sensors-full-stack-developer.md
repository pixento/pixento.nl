## The role

As software developer I'm responsible for maintaining and extending all applications and tooling at Abel Sensors, in both Python and PHP/Laravel.

## What I do

- Write and maintain algorithms for processing and analysing sensor data, including event detection in time-series data and processing point clouds through clustering.
- Split incoming sensor messages off into a separate microservice and roll it out in a scalable way (Laravel, Redis, Kubernetes).
- Set up a PostgreSQL database with TimescaleDB for storing and processing time-series sensor data.
- Build and maintain REST APIs and integrate third-party APIs (Laravel).
- Build and maintain CI/CD pipelines (Jenkins, Docker).
- Migrate a web application to a new hosting environment with minimal downtime, including the database (DigitalOcean, MySQL).
- Write a tool to update devices in the field remotely and deploy to on-site servers (Python, Docker Compose).
- Improve a Python application for monitoring bicycle parking facilities (OpenCV).
