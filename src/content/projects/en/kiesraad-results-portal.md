## The assignment

For the Electoral Council we're building a portal for viewing election results. The official results are delivered as EML files, which the application imports and processes.

## What I do

- Develop features in the Django backend and the React front-end.
- Make the import of election data more robust.
- Set up a Docker Compose development environment with backend, front-end, database and reverse proxy, including the Dockerfiles.

The application runs on a managed Kubernetes cluster at Scaleway.
